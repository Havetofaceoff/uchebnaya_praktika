Расчет индивидуальной скидки партнера:

Функция рассчитывает процент скидки партнера
на основе суммарного объема купленной продукции

Условия:

- менее 10 000 единиц — 0%
- от 10 000 до 49 999 — 5%
- от 50 000 до 299 999 — 10%
- от 300 000 — 15%

Тестирование:

Проверяются пограничные значения:

- 9999
- 10000
- 49999
- 50000
- 300000

Запуск:

python -m unittest test_partner_discount.py

Работа с базой данных

Для получения суммарного объема продаж используется PostgreSQL
и драйвер psycopg2.

Запрос использует LEFT JOIN между таблицами partners
и sales_history, а также SUM(quantity) для подсчета
общего количества приобретенной продукции.

Полученное количество передается в функцию
calculate_partner_discount.

Результат содержит:

- идентификатор партнера;
- название партнера;
- суммарное количество продукции;
- текущий процент скидки.
